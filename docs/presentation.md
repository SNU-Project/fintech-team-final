## 1. 문제 제기 (1분)

> "작년보다 연봉이 올랐는데 통장은 왜 더 빠듯할까요?"

- 명목 인상률과 물가상승률을 **내 연봉에 붙여서** 계산해 주는 곳이 없다
- 뉴스는 "물가 2.8%", 회사는 "인상률 4.2%"라고만 말한다
- **그런데 그 2.8%조차 내 물가가 아니다** — 같은 달에 교통은 +7.7%, 주류·담배는 +0.2%다
- 그래서 **내 물가가 얼마인지**, **얼마가 부족한지**, **무엇으로 메울지** 계산하는 도구를 만들었다

## 2. 데이터 (2분)

핵심 메시지: **모든 수치가 실제 데이터다. 지어낸 값이 하나도 없다.**

- 자산 5종 + 환율, 10년 월말 종가 — Yahoo Finance
- 한국 소비자물가지수 — OECD SDMX
- **실시간과 스냅샷을 나눈 이유**를 설명 (CORS 실측 결과 화면 공유)
  - 물가·환율·비트코인은 브라우저가 직접 실시간 조회
  - 10년 시계열은 CORS가 막혀 Actions가 매일 수집 → 애초에 실시간일 필요도 없음
- 정제 과정 2건 언급: 시간대 보정으로 매년 10월 복구, 오류 틱 1건 제거

## 3. 라이브 데모 (4분) — 시나리오 고정

**입력값을 미리 정해 두고 그대로 따라간다. 즉흥 입력 금지.**

### 3-0. 내 물가 (1분 30초) — **가장 중요한 구간**

여기가 우리 팀에만 있는 기능입니다. 시간을 아끼지 마세요.

값을 입력하는 순간은 전부 **설문(3문항)** 안에서 일어난다 — 리포트에 들어간 뒤로는
설문 입력값(생활 유형·월 생활비·세부 지출·연봉)이 전부 읽기 전용이다. 리포트를
"내가 답한 걸 계산해 보여주는 결과 화면"으로 못박아 둔 것이라, 바꾸려면 홈의
"처음부터 다시 입력하기"로 설문을 다시 풀어야 한다. 데모도 그 순서를 따른다.

1. 첫 화면 Q1의 **"혼자 생활비를 관리해요"** 를 가리킨다
   > "임의로 만든 프리셋이 아니라 국가데이터처 1인 가구 소비지출로 시작합니다."
2. Q2에서 `세부 항목 입력하기`를 열고 교통을 `20` → `60`만원으로 바꾼다
   → 총액과 도넛이 같이 바뀌는 것을 보여준다
   > "통계 평균은 시작점이고, 실제 체감의 차이는 내가 많이 쓰는 한 항목에서 생깁니다."
3. Q3에서 연봉(`3600`/`3750`)을 입력하고 **"리포트 보기"**
4. 리포트가 열리면 방금 답한 생활 유형·월 생활비·세부 지출이 카드 맨 위에
   **읽기 전용**으로 그대로 떠 있는 걸 가리킨다
   > "이제부터는 제가 답한 내용을 그대로 보여주는 결과 화면입니다. 여기서 숫자를
   > 눌러서 고칠 순 없어요 — 바꾸려면 설문을 다시 풀어야 합니다."
5. 헤드라인(**"당신은 다른 사람들보다 교통·통신 기준으로 더 비싸게 살고 있어요!"**)을 가리키고,
   그 아래 작은 글씨로 정확한 수치(공식 물가 2.8% · 내 물가 3.8%)가 보조로 붙어 있는 걸 짚는다
6. **"내 물가를 밀어올린 범인"** 5개 항목이 처음부터 다 펼쳐져 있는 것과, 1위가
   방금 고친 교통·통신인 걸 보여준다
   > "순위와 항목만 바로 보이게 했습니다. 궁금하면 '상세 계산 보기'에서 실제
   > 계산 과정을 한 줄씩 따라갈 수 있습니다."
7. 아이스 아메리카노 카드로 체감 환산까지 보여주고, 아래로 스크롤해 자연스럽게
   "실질임금 진단"으로 넘어간다(버튼 없이 리포트가 쭉 이어짐)

> **확장 스토리 한 줄** (질문 나오면): "지금은 지출을 직접 입력받지만,
> 카드 소비내역이 있으면 입력 없이 자동으로 계산됩니다. 금융앱의 소비 분석 데이터와 바로 붙는 구조입니다."

### 3-1. 실질임금 진단 (1분 30초)
1. 방금 설문에서 입력한 현재 연봉 `3600` / 내년 연봉 `3750`이 이 탭에도
   똑같이(읽기 전용으로) 반영돼 있는 걸 가리킨다
2. 상단 물가 배지를 가리키며 — "이 2.8%는 지금 OECD에서 실시간으로 받아온 값입니다"
3. 막대 3개 설명 → 결론 문장 읽기

### 3-2. 연봉 협상 가이드 (30초)
- "협상 테이블에서 말할 숫자는 136만원(연봉 3,736만원, 3.8%)입니다" — 물가 방어 100만원 + 실질 1%
- 퍼센트가 아니라 실제 금액으로 바로 와닿는다는 점 강조

### 3-3. 자산 타임머신 (2분)
1. **"자산 타임머신으로 확인하기 →"** 버튼을 눌러 펼친다(목표 자산/타임머신은 기본 리포트에는 없고 버튼으로 펼쳐야 나온다)
2. 시작 시점 `2021-08`, 금액 `1000`만원
3. 금 / KODEX 200 / S&P 500 체크 상태 확인
4. **회색 점선(물가선)을 가리키며** — "이 선 아래면 물가를 못 이긴 것"
5. 결론 문장 읽기: "금은 2,944만원, 연평균 +28.9%, 최대 낙폭 −16.2%"
6. **표를 보여주며** — "수익률만 보면 안 됩니다. 최대 낙폭은 그 수익을 얻기까지 견뎌야 했던 손실입니다"
7. **"시작 달이 조금 달랐다면?"** 표를 보여준다
   > "같은 자산도 앞뒤 6개월만 옮기면 결과가 달라집니다. 최고 한 점이 아니라 범위와 중앙값을 같이 봅니다."
8. 위로 돌아와 **"목표 자산 계획 보기 →"** 버튼도 눌러, 과거의 아쉬움을 현재 목표 계획으로 전환한다

## 4. AI 활용과 검증 (2분)

여기가 우리 팀의 차별점입니다. 겸손하게 말하지 말고 정확하게 말한다.

> "AI로 5명이 각자 프로토타입을 빠르게 만들었습니다. 그런데 합치면서 확인해 보니, **세 결과물 모두 데이터가 가짜였습니다.**"

1. **사인파로 만든 가짜 주가 곡선** — 코드 한 줄 띄우기 (`Math.sin`)
2. **API 실패 시 난수로 만든 백테스트** — `np.random.normal`
3. **잘못된 통계 코드** — 물가지수 자리에 금리 코드

> "화면상으로는 셋 다 정상 작동했습니다. 데이터 파이프라인을 직접 다시 짜면서 드러났습니다."

- 그리고 우리가 새로 짠 코드에서도 버그가 나왔다는 점까지 말한다 (이상치 필터가 비트코인 실제 데이터 50개월을 지웠던 건)
- AI 해설 버튼은 v6에서 화면에서 뺐다(리포트를 읽기 전용 결과 화면으로 단순화하면서).
  그래도 **계산 엔진과 언어 모델을 분리한 구조는 서버 코드(`api/insight.mjs`)에 그대로 남아 있다** —
  화면 대신 `safeText` 검증 로직을 코드로 짧게 보여준다: 전달한 숫자에 없는 값이 응답에
  나오면 통째로 버리게 되어 있다는 것
- 마무리: **"AI 활용의 실질은 얼마나 빨리 만들었나가 아니라, 어디를 의심하고 어떻게 확인했나였습니다."**

- [ ] 배포 URL을 **외부 네트워크**(휴대폰 테더링 등)에서 열어 확인 — 학교 와이파이에서만 되는 상황 방지
- [ ] 브라우저 콘솔 에러 0건
- [ ] 실시간 지표 3개(물가·환율·비트코인)가 모두 표시되는지
- [ ] 실시간 API가 죽어도 스냅샷으로 화면이 그려지는지 (네트워크 차단 후 테스트)
- [ ] 데모 시나리오 입력값으로 한 번 리허설
- [ ] 발표용 노트북 화면 배율에서 차트가 잘리지 않는지
- [ ] 다크모드/라이트모드 양쪽 확인 (발표장 프로젝터가 어떻게 나올지 모름)

## 예상 질문

**Q. 왜 실시간이 아닌 데이터가 있나요?**
Yahoo Finance가 CORS를 허용하지 않아 브라우저에서 직접 못 부릅니다. 대신 GitHub Actions가 주 1회 수집합니다. 10년 히스토리는 실시간일 필요가 없고, 발표처럼 동시 접속이 많을 때 외부 API 의존을 줄이는 이점도 있습니다.

**Q. 예금 3%는 어디서 나온 값인가요?**
시장 시세가 없어 유일하게 가정값으로 둔 항목입니다. 화면에 `가정값` 배지로 표시했고 README에도 명시했습니다.

**Q. 10년 수익률이 너무 좋게 나온 것 아닌가요?**
맞습니다. 2016~2026은 특정 국면에 치우친 구간입니다. 그래서 수익률 옆에 **최대 낙폭**을 표시하고, 선택한 시작일 앞뒤 6개월의 **결과 범위와 중앙값**도 함께 보여줍니다. 한 날짜의 최고 결과를 추천값처럼 쓰지 않습니다.

**Q. 팀원별 기여는?**
개인 리포 5개가 `SNU-Project` 조직에 그대로 남아 있고, README 6절에 각 결과물에서 무엇을 살리고 무엇을 버렸는지 표로 정리했습니다.
