# PR 전 자체 점검 — AI에게 시킬 것

작업을 마치고 PR을 올리기 전에, **AI에게 이 문서를 읽히고 아래를 시키세요.**

> "docs/pr-protocol.md 읽고, 지금 내 변경사항이 올려도 되는지 판정해줘."

---

## ⚠️ 먼저 알아둘 것

이 점검은 **대형사고를 막는 그물**이지 코드 품질 보증이 아닙니다.
🟢이 "좋은 코드"라는 뜻은 아니고 **"큰 사고는 안 났다"** 는 뜻입니다.
진짜 검증은 배포본을 사람이 직접 열어보는 것입니다.

그리고 AI는 자기 작업을 통과시키는 쪽으로 편향됩니다. 그래서 아래 항목은
전부 **"괜찮나요?"가 아니라 "결과를 붙여라"** 로 되어 있습니다.

---

## 1단계 — 지금까지 뭐가 있었는지 먼저 읽기

혼자 만들면 남이 이미 만든 걸 또 만들거나, 남이 고친 걸 되돌립니다.

```bash
git fetch origin
git log --oneline origin/main -15        # 최근 무슨 작업이 있었나
git diff --stat origin/main...HEAD       # 내가 뭘 바꿨나
```

**AI에게 물을 것:**
- 최근 커밋 중 내 작업과 겹치는 게 있나?
- 내가 건드린 파일을 최근에 다른 사람이 고쳤나? 그 의도를 되돌리고 있진 않나?

---

## 2단계 — 🔴 이 중 하나라도 해당하면 올리지 말 것

판단이 필요 없는, 사실 확인만으로 걸러지는 것들입니다.

| # | 조건 | 왜 |
|---|---|---|
| 1 | 난수·삼각함수로 화면에 보일 값을 만듦 (`Math.random`, `Math.sin`, `np.random`) | 이 프로젝트가 존재하는 이유가 사라짐 |
| 2 | API 키·토큰이 `assets/` 안 코드에 들어감 | 정적 파일은 전부 공개됨 |
| 3| `package.json`·vite·webpack 등 빌드 도구 추가 | 발표날 CI 깨지면 복구 불가 |
| 4 | `data/*.json`을 손으로 수정 | 파이프라인 산출물. 고치려면 `pipeline/`을 고칠 것 |
| 5 | 데모 기본값 변경 (연봉 3600/3750, 타임머신 2021-08·1000만원, 생활유형 "혼자 생활비를 관리해요") | 발표 리허설이 어긋남 |
| 6 | **8/18 이후의 기능 추가** | 발표 3일 전부터 동결. 버그 수정만 |

1~4번은 PR을 올리면 CI가 자동으로 잡습니다. 5~6번은 사람만 압니다.

---

## 3단계 — 🟡 이 경우엔 단톡에 한 줄 남기고 올리기

머지해도 되지만 **다른 사람이 알아야** 하는 것들입니다.

- `assets/js/engine.js` 를 고침 → 계산 결과가 바뀔 수 있음
- `pipeline/` 을 고침 → 데이터가 바뀔 수 있음
- 다른 사람이 최근에 작업한 파일을 같이 고침
- 공용 CSS 변수(`:root` 안의 `--brand`, `--series-*` 등)를 바꿈 → 사이트 전체 영향
- 화면 문구를 바꿨는데 투자 권유처럼 읽힐 여지가 있음

---

## 4단계 — 증거 남기기 (실제로 돌리고 결과를 붙일 것)

```bash
node --check assets/js/app.js        # 문법
python3 -m http.server 5173          # 띄우고 브라우저에서 확인
```

브라우저 콘솔에 붙여넣고 결과를 PR에 적으세요:

```js
// 가로 스크롤 (모바일에서 제일 자주 깨짐)
console.log(document.body.scrollWidth, document.documentElement.clientWidth);
// 두 값이 같아야 정상

// 탭이 하나만 보이는지
console.log([...document.querySelectorAll('.panel')].filter(p=>!p.hidden).map(p=>p.id));
// 하나만 나와야 정상
```

> 로컬에서 OECD CORS 에러가 뜨는 건 **정상**입니다. 배포 도메인만 허용돼 있어요.
> JS·CSS를 고쳤는데 반영이 안 된 것 같으면 **⌘+Shift+R**.

## 5단계 — PR 본문에 이 블록 붙이기

```markdown
## 자체 점검

판정: 🟢 (또는 🟡 — 이유)

- 최근 커밋과 겹침: 없음
- 🔴 조건 6개: 해당 없음
- 가로 스크롤: 375 === 375
- 콘솔 에러: 0건
- 변경 파일: assets/css/styles.css
```

🟡이면 단톡에 "이거 머지합니다" 한 줄만 남기고 올리세요. 회의는 필요 없습니다.
