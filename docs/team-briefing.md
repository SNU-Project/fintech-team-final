## 0. 한 문장으로

**"연봉이 올랐는데 왜 통장은 더 빠듯하지?"** — 이 질문 하나를 실제 데이터로 끝까지 파고드는 웹앱입니다.

탭 4개가 그 질문을 푸는 4단계입니다.

```
① 내 물가       내 체감 물가는 얼마인가?        기준을 세운다
② 실질임금 진단  그 물가를 내 연봉이 이겼나?      진단한다
③ 목표 자산     부족하면 얼마를 모아야 하나?     처방한다
④ 자산 타임머신  그 돈을 굴렸으면 어떻게 됐나?    근거를 댄다
```

## 1. 내 물가 — 우리 팀의 차별화 기능

### 무슨 문제를 푸나

뉴스에서 "물가 2.8% 올랐다"고 합니다. 이건 **전 국민 평균 장바구니** 기준입니다.

그런데 품목별로 뜯어보면 오른 정도가 완전히 다릅니다.

| 품목 | 상승률 |
|---|---|
| 교통 | **+7.7%** |
| 오락·문화 | +5.5% |
| *전체 평균* | *2.8%* |
| 통신 | +0.7% |
| 주류·담배 | **+0.2%** |

**최고와 최저가 7.5%p 차이**입니다. 그러니 차로 출퇴근하는 사람과 지하철만 타는 사람의 체감이 같을 리 없습니다.

### 어떻게 계산하나

가중평균입니다. 어려운 수식이 아닙니다.

```
내 물가 = (교통 비중 × 교통 물가) + (식료품 비중 × 식료품 물가) + … (12품목)
```

지출 슬라이더를 밀면 비중이 바뀌고, 그래서 숫자가 실시간으로 움직입니다.

### 결과

라이프스타일에 따라 이렇게 갈립니다.

| | 내 물가 |
|---|---|
| 차로 출퇴근 | **3.7%** |
| 외식·구독 많은 1인 | 3.1% |
| *공식 발표* | *2.8%* |
| 집밥·대중교통 | **2.2%** |

### 여기서 나오는 반전 — 발표의 하이라이트

**집밥파는 지금 물가가 가장 낮은데, 10년 누적으로는 가장 높습니다.**

식료품이 최근에는 +0.9%로 잠잠하지만 **10년 동안 +43%** 올랐기 때문입니다. 화면이 이 이유를 자동으로 설명해 줍니다.

> 최근 한 달 물가만 보면 놓치는 부분입니다.

### 예상 질문

**Q. 지출 비중은 어디서 가져왔나요?**
국가데이터처 가계동향조사(2025년 4분기)의 가구원수별 평균입니다. 시작값일 뿐이고 사용자가 슬라이더로 바꿉니다.

**Q. 그게 왜 중요한가요?**
연봉 협상 기준이 달라집니다. 내 물가가 3.7%인데 2.8%만 올려받으면 실질적으로 삭감입니다.

## 2. 실질임금 진단

### 핵심 개념: 물가 유지선

**작년과 똑같이 살려면 필요한 연봉**입니다.

```
물가 유지선 = 올해 연봉 × (1 + 내 물가)
            = 3,600만원 × 1.028 = 3,700만원

내년 연봉 3,750만원 > 3,700만원  →  이겼다
```

막대 3개(현재 연봉 / 내년 연봉 / 물가 유지선)로 한눈에 보입니다.

### 특별히 봐야 할 것

**① 며칠 더 일해야 하나**
"연 138만원 부족"보다 **"작년처럼 살려면 9일 더 일해야 한다"** 가 훨씬 와닿습니다. 부족분을 하루 일당으로 나눈 값입니다.

**② 격차는 해마다 벌어집니다**
매년 0.5%p씩 밀리면 복리로 쌓입니다. 10년 뒤 격차를 곡선 두 개로 보여줍니다.

**③ 연봉 협상 가이드**
"협상 테이블에서 말할 숫자는 3.8%입니다" — 물가에 실질 인상 1%를 더한 값. 실무에서 바로 쓸 수 있는 결과입니다.

## 3. 목표 자산 모으기

"3년 안에 5,000만원" 같은 목표를 넣으면 **매달 얼마가 필요한지 역산**합니다.

```
필요 월 저축 = (목표 − 현재 자산이 불어난 값) ÷ 복리 계수
```

투자 성향에 따라 기대수익률이 달라지고, 필요한 저축액도 달라집니다.

| 성향 | 기대수익률 | 연 변동성 |
|---|---|---|
| 안정형 | 3.8% | 7.1% |
| 균형형 | 6.7% | 9.9% |
| 적극형 | 13.0% | 16.5% |

**이 수익률은 우리가 정한 게 아닙니다.** 각 성향의 구성 자산이 지난 10년간 실제로 낸 수익률의 가중평균입니다.

## 4. 자산 타임머신

### 무슨 역할인가

3번에서 "6.7% 수익률"이라고 했는데, **"진짜야?"** 라는 질문에 답하는 곳입니다.

실제 10년 월말 종가로 **"2021년 8월에 1,000만원 넣었으면 지금 얼마"** 를 계산합니다.

```
금           2,944만원  (+194%)
KODEX 200    2,331만원  (+133%)
S&P 500      2,077만원  (+108%)
──────────────────────────────
물가만큼      1,166만원   ← 회색 점선. 이 아래면 진 것
```

### 반드시 같이 말해야 할 것

**수익률만 보여주면 안 됩니다.** 그래서 최대 낙폭을 나란히 놓습니다.

| 자산 | 10년 수익률 | 최대 낙폭 |
|---|---|---|
| 비트코인 | +64%/년 | **−74.6%** |
| KODEX 200 | +14.4%/년 | −35.6% |
| 금 | +18.8%/년 | −16.9% |
| 국고채10년 | **−1.7%/년** | −19.8% |

> "비트코인이 제일 많이 올랐지만, 그 수익을 얻으려면 자산이 4분의 1로 줄어드는 걸 견뎌야 했습니다."

국고채가 마이너스인 것도 그대로 보여줍니다. 유리한 것만 고르지 않았다는 증거입니다.

## 5. 데이터 — 이게 우리 프로젝트의 핵심입니다

### 지어낸 숫자가 하나도 없습니다

| 데이터 | 출처 | 갱신 |
|---|---|---|
| 물가 (전체 + 12품목) | OECD | 🟢 접속할 때마다 실시간 |
| 원/달러 | 유럽중앙은행 | 🟢 접속할 때마다 실시간 |
| 비트코인 | CoinGecko | 🟢 접속할 때마다 실시간 |
| 주식·금·채권 10년 | Yahoo Finance | 🟢 주 1회 자동 |
| 예금 금리 | OECD | 🟢 주 1회 자동 |
| 가구 지출 통계 | 국가데이터처 | 🟡 분기 수동 (화면에 시점 표시) |

**예금까지 실제 금리로 바꿔서, 이제 화면에 가정값이 없습니다.**

### 왜 전부 실시간이 아닌가 — 자주 나오는 질문

브라우저에서 API를 직접 부르려면 그 API가 **CORS를 열어줘야** 합니다. 실측 결과:

```
OECD, 유럽중앙은행, CoinGecko  →  허용   ✅ 실시간 가능
Yahoo Finance                 →  차단   ❌ 브라우저에서 불가
```

그래서 **지금 이 순간 값이 의미 있는 것**(물가·환율·코인)은 실시간으로 부르고, **10년 시계열**은 GitHub Actions가 주 1회 받아옵니다. 10년 히스토리는 애초에 실시간일 필요도 없고요.

부수 효과로 발표 당일 안정성도 확보됩니다. 평가자 여러 명이 동시에 들어와도 스냅샷이 바닥에 깔려 있어 화면은 항상 그려집니다.

## 6. AI 활용 — 채점 7번

여기가 우리 팀에서 제일 할 말이 많은 부분입니다.

### 앱 안의 AI

"내 물가" 결과를 Gemini가 쉬운 말로 풀어 줍니다. 그런데 그냥 붙인 게 아닙니다.

**모델이 전달받지 않은 숫자를 답변에 쓰면 응답을 통째로 버립니다.** "데이터를 지어내지 않는다"는 원칙을 AI 출력에까지 적용한 것입니다.

### 진짜 핵심 — AI 결과물을 검증한 과정

AI로 각자 프로토타입을 빠르게 만들었습니다. 그런데 합치면서 확인해 보니 **세 결과물 모두 데이터가 가짜였습니다.**

1. **사인파로 만든 가짜 주가 곡선** — 과거 성과라면서 `Math.sin`으로 곡선을 생성
2. **난수로 만든 백테스트** — API 실패 시 `np.random.normal`로 가격을 지어냄
3. **잘못된 통계 코드** — 물가지수 자리에 금리 코드

**셋 다 화면상으로는 정상 작동했습니다.** 데이터 파이프라인을 직접 다시 짜면서 드러났습니다.

우리가 새로 짠 코드에서도 5건 더 나왔습니다. 예를 들어 이상치 필터를 "중앙값 대비 3배"로 짰다가 **비트코인의 실제 관측치 50개월을 삭제**한 적이 있습니다. 비트코인은 10년간 진짜로 100배 올랐거든요.

> **"AI 활용의 실질은 얼마나 빨리 만들었나가 아니라, 어디를 의심하고 어떻게 확인했나였습니다."**

## 7. 자주 나올 질문 대비

**Q. 예금 수익률 2.1%는 어디서 나왔나요?**
OECD 한국 3개월 은행간금리를 월 복리로 굴린 값입니다. 원래 3.0%를 가정값으로 썼는데, 실제로 계산해 보니 1%p 가까이 후하게 잡고 있었습니다.

**Q. 10년 수익률이 너무 좋게 나온 것 아닌가요?**
맞습니다. 2016~2026은 특정 국면에 치우친 구간입니다. 그래서 수익률 옆에 **최대 낙폭**을 반드시 같이 보여줍니다. "계산 근거" 섹션에도 한계로 적어 뒀습니다.

**Q. 투자 추천인가요?**
아닙니다. 화면 하단에 명시했습니다 — 투자 권유나 재무·법률 자문이 아니며, 과거 수익률은 미래를 보장하지 않습니다.

**Q. 팀원별 기여는?**
개인 리포 6개가 `SNU-Project` 조직에 남아 있고, README 8절에 누구 것에서 무엇을 살리고 무엇을 뺐는지 표로 정리했습니다.

**Q. 데이터가 안 맞으면 어떻게 아나요?**
매주 자동 갱신 때 검증이 돌아갑니다. 관측치 부족, 비정상 CAGR·변동성, −99% 이하 낙폭(오류 신호)이 감지되면 갱신을 막습니다.
